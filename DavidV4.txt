""" affordance_engine.py — David v4.0 Improvement 1: Semantic Affordances Replaces single-pixel targeting with UV-mapped contact-point heatmaps. Architecture ------------ The AffordanceEngine wraps a lightweight torchvision object detector (FCOS or MobileNetV3 SSD) and a small MLP "affordance head" trained to classify each pixel of a detected object's bounding box into functional-part categories: handle · rim · blade · lid · button · body · edge · tip For each detected object it returns an AffordanceMap: - A list of AffordancePoint candidates, sorted descending by score. - The best candidate (highest score) is used by PlannerNode as the precise contact point instead of the object's centre pixel. Training data ------------- The affordance head is initialised with weights from a small synthetic dataset of household objects (mugs, knives, screwdrivers, bowls, bottles) labelled with contact-point UV maps. The AutoCalibrator provides fine-tuning signal at runtime: misaligned grasps are flagged as negative examples. Integration points ------------------ VLAAdapter.generate_action() → calls AffordanceEngine.extract(rgb, depth, object_label) PlannerNode._plan_and_dispatch() → reads vla_resp.affordance_map.best MotorPrimitiveMsg → contact_point_xyz, contact_label populated """ from __future__ import annotations import logging from typing import Optional import cv2 import numpy as np from cognitive_core.schemas import AffordanceMap, AffordancePoint logger = logging.getLogger(__name__) # Minimum score for an affordance candidate to be included in the map AFFORDANCE_MIN_SCORE = 0.25 # Functional part labels and their typical locations within a bounding box # expressed as (u_centre, v_centre, u_radius, v_radius) in normalised [0,1] UV space. # These are heuristic priors; the MLP head refines them per object. 4. cognitive_core/dreamer.py — NEW (replaces stub)

""" dreamer.py — David v4.0 Improvement 2: Predictive Dreamer Loop Implements a lightweight Latent World Model (JEPA-inspired) that runs a "Mental Simulation" of the next N seconds before any arm motion is dispatched. Architecture ------------ The Dreamer receives: - current_frame : latest RGB-D numpy array - proposed_vector : [dx, dy, dz] unit vector of the planned arm motion - horizon_s : simulation horizon in seconds (default 2.0) It outputs a DreamerResult: - collision_prob : estimated probability of collision within horizon_s - safe_vector : alternative motion vector if collision_prob > threshold Implementation Strategy ----------------------- Full Video Diffusion Models (e.g., Stable Video Diffusion) are too slow for real-time use on edge hardware. This implementation uses a two-tier approach: FAST PATH (< 5 ms): Geometric depth-based forward projection. - Projects the arm's swept volume along proposed_vector. - Checks against the current OccupancyGrid voxels. - Returns collision_prob = occupied_fraction.
